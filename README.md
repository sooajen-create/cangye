# 藏页 · 私人同人书库

适合安卓手机与电脑的私人收藏 Web 应用。**界面源码可以公开，作品和原始文件只存在你自己的 Supabase 项目或本机浏览器中，不放进 GitHub 仓库。**

已部署：https://sooajen-create.github.io/cangye/ 。这个部署已预配置主人的 Supabase 项目，直接使用本人创建的书库账号登录即可。不要重复执行首次安装 SQL。部署核验见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 已实现

- 邮箱密码登录；SQL 指定唯一主人；前端没有注册及公开分享入口。
- Supabase 数据库保存独立正文、分类与阅读进度；私有 Storage 桶保存上传的原件。
- 本地模式使用 IndexedDB，不需账号，可先体验文件导入、分类、阅读、备份。
- 多链接队列；尝试提取四个平台的 HTML 正文；失败明确报错，不以书签代替正文。
- TXT / HTML / XHTML / EPUB / PDF / DOCX / Markdown / ODT / FB2 多文件导入，单文件 20 MB，正文 12 MB；保留原始文件。
- CP → 作者 → 作品树；文件夹路径、标签、合集；多选批量分类；标题、作者和全文搜索。
- 阅读器：章节目录、字号、衬线/无衬线、暖纸/纯白/夜间、阅读进度。
- 全库或选中作品 ZIP 导出，包含正文、分类、阅读进度与可选原始文件；备份恢复；单篇 TXT 导出。
- 版本号防止两台设备静默覆盖作品元数据；阅读进度以最后一次成功提交为准。

## 必须了解的边界

### 新增格式说明

| 格式 | 提取方式与限制 |
|---|---|
| PDF | 本机 PDF.js 提取可复制文字，按页生成目录，最多 300 页；不含 OCR。扫描、加密或无文字的 PDF 明确拒绝，混合文件的无文字页会提示核对。多栏与断行可能影响顺序。 |
| DOCX | 提取正文、表格文字及标题/作者；不保证页眉页脚、脚注、文本框和图片。旧 `.doc` 请先转换。 |
| Markdown | `.md` / `.markdown`，按标题分章，支持简单 title/author 前置信息；保留部分 Markdown 标记，不执行 HTML。 |
| ODT | 提取正文文字与元数据，复杂排版请查看原件；加密文件需先解密。 |
| FB2 | 按嵌套分节提取正文与书籍元数据；图片保留在原文件。 |

文档在当前设备解析，不发送到第三方转换或 OCR 服务。PDF.js、中文 CMap 和标准字体资源随网站提供，首次 PDF 导入会额外加载约数 MB。原始文件和提取后的正文仍同步到本人的 Supabase 项目。所有格式默认待核对。

1. **文件导入及本地保存可直接使用。云同步和链接导入必须先配置自己的 Supabase 项目。**未连接时界面明确显示“本地模式”，不会伪装成云端成功。
2. 链接导入是尝试提取，不保证四个平台永久兼容。未对真实平台文章逐篇实测。AO3 自动请求全文页；Asianfanfics 尝试识别当前页面同作品章节链接，最多 80 个；LOFTER/微博不自动追踪合集、评论续文或外链正文。
3. 不绕过原站账号、付费、私密权限、验证码或反爬。服务端无法继承你手机浏览器的登录状态。可保存本人合法可访问页面为 HTML 后上传，或粘贴正文。
4. 阅读器以文字为主，**不下载远程图片、音频、视频**。图片文需另外下载原图；EPUB 内图片保留在原始 EPUB 中，可下载原件在电子书阅读器中查看。
5. 成功提取的作品默认“待核对”。请检查章节数、最后一段，再标记“已核对”。“永久副本”指独立于原链接，不表示服务永不关闭或不会丢失；请保留本地 ZIP。
6. **没有端到端加密。**隐私来自账号、唯一主人校验、RLS 和私有文件桶。云端运营方仍可能依适用政策或法律处理数据。已登录设备可读取内容；退出会清除会话，但本地试用库会保留。
7. 本地模式不云同步；清除浏览器网站数据会丢失本地模式收藏。通过“导出整库 → 云端登录 → 恢复备份”迁移。
8. Supabase 免费项目可能因低活跃暂停，没有免费自动每日备份承诺。不要把免费云端当作唯一副本。
9. 云端读取按 100 篇分页，当前前端上限 10000 篇；大型书库的全文加载会消耗内存与流量。备份恢复上限 100 MB（解压 180 MB），适合小型私人文本库，较大收藏应分批操作。
10. 安卓友好响应式 Web 应用；本版本没有完整离线 PWA 或后台导入服务。请保持页面打开等待队列完成，云端阅读进度在滚动停止、换章、返回书库时提交；关闭浏览器前留出片刻。

## 开始使用

详见 [DEPLOY.md](DEPLOY.md)。应用无构建依赖，不需要付费模型 API。

本机预览：在项目目录执行 `python -m http.server 4173`，浏览器访问 `http://localhost:4173`。不能直接双击 `index.html`（ES Modules 需要 HTTP）。

测试：`node --test tests/*.test.mjs`。浏览器解析测试位于 `/tests/browser.html`，只使用自制内存样例，不读取账号或收藏、不写入书库。Pages 发布该测试页用于验证浏览器的 XML、EPUB 和 PDF worker 解析。

## 项目结构

| 文件 | 用途 |
|---|---|
| `index.html`、`style.css`、`app.js` | 登录、书库、分类、阅读器、导入、备份界面 |
| `importer.js` | TXT / HTML / EPUB 解析与备份记录验证 |
| `store.js` | Supabase REST 登录、RLS 数据访问、原件存储与本地模式 |
| `supabase/setup.sql` | 唯一主人、表、私有文件桶、RLS 和导入限流 |
| `supabase/functions/import-link/index.ts` | 限制域名与跳转、限体积、验证账号的网页获取函数 |
| `.github/workflows/pages.yml` | 只发布前端文件，不发布 SQL、函数和测试 |
| `vendor/` | 本地 JSZip 与许可证，不依赖第三方 CDN |
